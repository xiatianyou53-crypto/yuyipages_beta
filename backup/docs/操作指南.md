# 操作指南（社员使用）

> 这份文档给**发布内容的同学**看：如何登录后台、上传新一期校报、发布文章。
> 如果网站还没部署好、或你进不了后台，请先找管理员（见《部署指南》）。

---

## 1. 访问与登录

1. 打开浏览器，访问：
   ```
   https://你的网站地址/admin/
   ```
2. 如果管理员开启了"访问门"，会先要求你通过身份验证（邮箱收验证码或社媒账号）。
3. 然后按站点设定的登录方式登录：
   - **方案 A**：点 **Login with GitHub**，用被授权加入仓库的 GitHub 账号登录。
   - **方案 B**：输入管理员发给你的邮箱和密码。
4. 登录成功后会看到后台界面（中文），左侧是内容列表。

> 打不开或登录失败 → 联系管理员，不要自己乱改代码。

---

## 2. 后台界面快速认识

- **左侧/顶部 "校报"**：管理每一期校报。
- **左侧/顶部 "文章"**：管理校园文章。
- 每个列表上方都有 **New / 新建** 按钮。
- 文章列表右上角可切换 **已发布 / 草稿** 视图。

---

## 3. 发布一期新校报（含上传 PDF）

1. 点 **校报 → New（新建）**。
2. 依次填写：
   - **标题（期名）**：如 `第59期·期中特辑`。
   - **期数**：填数字，如 `59`（会显示在卡片上，别和标题里重复错乱）。
   - **出版日期**：选一个日期时间。
   - **PDF 文件**：点空白框或用鼠标**把 PDF 拖进来**，选择本机文件上传。
   - **封面图（可选）**：不传也没关系，前端会显示默认封面；要换点这里上传图片。
   - **简介**：一两句话介绍本期内容（可选）。
3. 点右下角 **保存（Save）**。
4. 保存后系统会自动把文件提交到 Git 并触发网站重建，等 **30 秒~1 分钟** 刷新前台即可看到。

> 小提示：PDF 建议小于 10MB。文件名最好别用空格和特殊符号。

---

## 4. 编辑已有校报

1. 在"校报"列表点要改的那一期。
2. 修改字段后点 **保存**。要撤掉本次修改可点 **Reset changes**。

---

## 5. 发布一篇文章

1. 点 **文章 → New（新建）**。
2. 填写：
   - **标题**：文章题目。
   - **发布日期**。
   - **正文**：直接写，或用工具栏把文字加粗、加小标题、插图（正文里插入的图片会自动上传）。
   - **封面图（可选）**：文章列表缩略图。
3. 点 **保存**，同样等自动部署后在前台可见。

> 想先写好不马上发：看你的后端是否支持"草稿/保存"（方案 A 直接发布；方案 B 若开启了审核
> 流程，保存后是草稿，需管理员点"发布"才会上线）。

---

## 6. 保存之后发生了什么（心里有数，少焦虑）

```
你点“保存”
   → Decap 把改动提交到 GitHub main 分支
   → Cloudflare/Netlify 检测到新提交，自动重新构建
   → 前台更新（通常 30 秒~1 分钟）
```

所以：**保存≠立刻看到**，等一会儿刷新（可强制刷新 Ctrl+F5）就出现了。

---

## 7. 常见问题

| 现象 | 怎么办 |
|---|---|
| 上传 PDF 一直转圈 | 文件太大（>10MB）建议压缩或联系管理员走大文件通道；检查网络 |
| 保存报错 | 截图给管理员；通常是你对该仓库没有写权限 |
| 前台没更新 | 等 1 分钟再刷新；仍不行看是不是 Build 失败（联系管理员看日志） |
| 校报详情 PDF 预览空白 | 某些浏览器/跨域不预览，点页面上的"下载 PDF"按钮用本机阅读器打开 |
| 中文乱码 | 正常写即可（全站 UTF-8）；不要用记事本另存成 GBK |
| 不知道封面图 | 可暂不填封面，前端会显示统一默认封面 |

---

## 8. 别忘了
- 发布前请社长或负责同学**校对内容与错别字**。
- 校报 PDF 上传前请确认是**定稿版**，避免反复覆盖。
- 涉及肖像/隐私的内容请征得同意再发。
