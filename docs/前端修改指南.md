# 网页前端修改指南（自助改版）

> 适用对象：会看文件、想自己改"外观/文字/图片/导航"的人（不一定要会编程）。
> 原则：**改哪里→打开哪个文件→保存→git push→等自动发布**。不要乱删文件、不要改看不懂的代码块。
> 若只是发校报/文章，用后台 `/admin/` 最省事，不用看本指南（见 `docs/操作指南.md`）。

---

## 0. 改之前：建议先在本地预览

1. 电脑装 [Hugo Extended](https://gohugo.io/installation/)。
2. 在这个项目根目录运行：
   ```bash
   hugo server
   ```
3. 浏览器打开 `http://localhost:1313`，改动后会自动刷新，确认没问题再提交。

> 不想本地预览也行：直接改完 push，等线上自动构建后再看。

## 1. 最常改的东西，查这张表

| 想改什么 | 打开/改哪个文件 |
|---|---|
| 网站名称/副标题/一句话介绍 | `config.yaml` 的 `title`、`params` |
| 整站配色 | `assets/css/main.css` 顶部 `:root` 里的颜色 |

| 顶部 logo | 替换 `static/images/logo.svg` |
| 顶部菜单（首页/校报/文章/关于） | `config.yaml` 的 `menu.main` |
| 页脚文字/版权 | `layouts/partials/footer.html` |
| "关于我们"整页文字 | `content/about.md` |
| 校报/文章内容 | 用后台 `/admin/`；或改 `content/` 下的 `.md` |

## 2. 改站名与首页文字

打开 `config.yaml`：

```yaml
title: '学校名 + 社团名'                 # 浏览器标签页/顶部名称
params:
  author: '社团名'
  description: '一句话站点描述（用于搜索引擎）'
  heroTitle: '首页大标题，如：用心记录，向世界发声'
  heroSubtitle: '大标题下面那行小字'
  aboutTitle: '首页"关于我们"区块的小标题'
  aboutBody: >                          # 首页关于区块正文
    换成一两段社团简介文字。
```

改完保存即可。

## 3. 改配色（整站清新校园风的主色）

打开 `assets/css/main.css`，最上面 `:root { ... }` 里就是颜色变量，只改这里，全站颜色随之变：

```css
:root {
  --primary: #2f7fb8;      /* 主色：按钮、链接、标题(校园蓝) */
  --primary-dark: #20597f; /* 深色：页脚、强调 */
  --accent: #f2b53c;       /* 点缀色：横线、角标(暖阳金) */
  --ink: #2b3a45;          /* 正文文字颜色 */
  ...
}
```

想快速知道某颜色值：网上搜"颜色选择器/色卡"得到十六进制，如 `#1e90ff` 替换 `--primary`。

## 10. 图片与 PDF 放哪、怎么引用

| 用途 | 放这里 | 代码里这样引用 |
|---|---|---|
| 站点素材（logo/封面/轮播） | `static/images/` | `/images/文件名` |
| 校报/文章上传的 PDF 与配图 | `static/uploads/` | `/uploads/文件名`（后台上传也进这） |

规则：**放进 `static/` 里任何子目录的文件，都会原样上线**；在 Markdown/配置里用 `/子目录/文件名` 引用即可。

## 11. 改完如何上线

本项目是 git 自动构建：改动 → 提交 → 推送到 GitHub `main` → 云端自动重新生成 → 上线。

在项目根目录执行：
```bash
git add -A
git commit -m "改了什么"
git push
```
等约 30 秒~1 分钟刷新线上页面即可看到。没变就强制刷新（Ctrl+F5）或等一等（有缓存）。

> 提交前最好先 `hugo server` 本地预览一遍，避免把打不开的页面推上去。

## 12. SEO：标题和描述怎么设

- **整站默认描述**：`config.yaml` 的 `params.description`。
- **单页自定义**：在该页 `.md` 的元数据里写 `description: ...`，会覆盖默认值并出现在该页的 `<meta description>`。
- 标题：单页用 `title`，整站用 `config.yaml` 的 `title`。已由模板自动拼成"页面标题 · 站名"。

## 13. 安全与注意事项

- **不要提交任何密钥/口令**（如 GitHub 的 Client Secret）。示例里的都是占位，请替换成自己的。
- 不要删 `content/` 与 `static/` 里的关键目录，除非你知道在做什么。
- 不要改动 `public/`（那是自动生成的，改了也会被覆盖）。
- 图片建议压缩后上传（网络快、省空间）。
- 改模板（`layouts/`）前先备份，改错可在 git 里 `git checkout .` 还原整树到上次提交。

> 出问题想回到上次能用的版本：`git checkout .`（放弃未提交改动）或 `git reset --hard HEAD`（慎用）。
